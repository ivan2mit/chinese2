Разбор черт по acjk — инструменты проверки

Страницы работают без сети и без сервера: все данные вшиты прямо в файлы. Каждая открывается двойным щелчком из файловой системы.

1

38 базовых черт: где какая встречается

Слева список из 38 черт, справа все иероглифы HSK, где рекурсивное разложение acjk дало эту черту, с подсветкой её положения. Клик по иероглифу переключает скелет на настоящий контур.
2

Форма спорных черт

Символы, которые не рисует шрифт (𠃌 乀 乚 乛 𠄌 𡿨), показаны настоящими чертами из глифов. Нужно, чтобы решить, что́ из них называть как.
3

Сопоставление черт

Заполняется вручную: слева символ, до которого доходит разложение, справа 38 базовых черт. Готово 28 из 30, не решены 乀 и ㇡.
4

Проверка носителем

Все 1201 иероглиф по одному: глиф, назначенные названия черт, отметка спорных мест с выгрузкой в JSON.

Что внутри

Данные — data/dictionaryZhHans.txt (8052 записи) и data/hsk3*.json из AnimCJK. Разбор acjk написан с нуля и проверен на всех 1201 иероглифах: число черт в выражении совпадает с числом черт в SVG, длина списка названий тоже.
